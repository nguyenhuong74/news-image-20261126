A one-image summary of Thursday 26 November 2026's world news, drawn by a
stdlib-only Python program. The image is a newspaper front page: a masthead
naming the day, six illustrated stories (US tariffs on 14 partners, Ukraine's
strike on a Russian airbase, Kim Jong Un's nuclear order, the FCC clearing
SpaceX for a million satellites, South Korea's rate hike, the end of the
Cartagena supermarket siege), and a footer noting the postponed Macy's
Thanksgiving Day Parade. Every story was checked against wire reports of
the day; nothing speculative is shown as fact.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, deterministic — every run produces
the same bytes). The program uses only the Python standard library and needs
no network.
